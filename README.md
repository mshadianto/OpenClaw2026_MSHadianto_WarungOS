## 🎯 The Problem

64 million UMKM in Indonesia. Warung owners spend 4+ hours daily on manual ops: inventory tracking, supplier hunting, customer follow-ups. 80% fail within 5 years.

## ⚡ The Solution

WarungOS is an autonomous multi-agent system where 3 specialized AI agents collaborate as a complete operations team:

- 🔍 **Inventory Sentinel** — Vision OCR + depletion forecasting
- 💼 **Procurement Negotiator** — Multi-criteria supplier selection + DOKU MCP payment
- 📱 **Customer Concierge** — Personalized WhatsApp/Telegram notifications
